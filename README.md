# Kampus

Hyper-localized social discovery platform — campus conversations, news, communities and people across Nigeria.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
npm i
npm run dev
```

Set the required `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY` environment variables (in `.env`) before running.
